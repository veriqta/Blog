## 0.2 Configure AWS CLI (5 minutes)

Run this in your terminal:

```bash
aws configure
```

Enter:
```
AWS Access Key ID: (create one in IAM → Users → your user → Security credentials)
AWS Secret Access Key: (shown only once when you create it)
Default region name: us-east-1
Default output format: json
```

**Verify it works:**
```bash
aws sts get-caller-identity
```

You should see your Account ID and user ARN. If you see an error, stop here and fix it.

---

## 0.3 Create an SSH Key (2 minutes)

```bash
aws ec2 create-key-pair \
    --key-name veriqta-ha-webapp-key \
    --key-type rsa \
    --key-format pem \
    --query 'KeyMaterial' \
    --output text > veriqta-ha-webapp-key.pem

chmod 400 veriqta-ha-webapp-key.pem
```

**Save this file.** If you lose it, you cannot recover it from AWS.

## 0.4 Important Notes (Read These)

**If you close your terminal and come back later:**
Some commands use "variables" like `$VPC_ID`. If you return tomorrow and a command fails because the variable is empty, simply re-run the command that created it, or look up the resource in the AWS Console. Every resource is tagged with `Project=Veriqta-HA-WebApp`, so you can find it easily.

**If you don't have a domain name:**
Phase 10 uses a custom domain. If you don't own one, **skip Phase 10 entirely.** Your application will still work perfectly using the ALB's default URL (something like `veriqta-ha-alb-123456789.us-east-1.elb.amazonaws.com`). You do not need a domain for this project to be complete.

**If you are on Windows:**
This project uses Linux-style commands. Windows users should use **WSL2** (Windows Subsystem for Linux) or a cloud-based terminal like AWS CloudShell. If you cannot use WSL2, you can still follow along using the AWS Management Console for most steps, though the commands will differ slightly.

**Costs:**
Running this project costs approximately **$15–25 per day** while you are actively building. When you are done, follow the Cleanup section at the end to destroy everything and stop charges.
